# SafeDrive AI Documentation

This `docs/` directory is the canonical source for Phase 1 documentation: architecture, API specifications, schedules, communication guidelines, and the project timeline.

## Structure

- `architecture/` — system diagrams and design notes
- `api/` — OpenAPI specs and API examples
- `timeline/` — project Gantt and dependencies
- `communication/` — Slack/Discord channel plan and comms norms
- `schedule/` — meeting agendas and calendar files (ICS templates)

## Contributing

- Keep diagrams in plain text (Mermaid) alongside rendered exports when needed
- Update OpenAPI first; generate clients/servers from it when possible
- Prefer small PRs with clear summaries; link tasks to the weekly tracker

## External docs (to be set up by PM)

- Notion/Google Drive workspace for non-code artifacts and meeting notes
- Shared folders for demo assets and videos
