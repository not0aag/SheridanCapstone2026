# Meetings — Phase 1

This schedule defines our recurring meetings for the prototype phase (Nov 5–Dec 4, 2025).

## Monday Stand-up (09:00, 30 minutes)

Agenda:

- Review last week's progress
- Plan this week's priorities
- Discuss blockers and dependencies
- Assign action items

## Friday Review (16:00, 1 hour)

Agenda:

- Demo progress (show what you built)
- Findings and learnings
- Documentation updates
- Plan next week
- Celebrate wins

Owners:

- PM (Alen) keeps calendar up to date
- All members RSVP and keep calendar current
